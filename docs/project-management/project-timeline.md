# PayChauki – Project Timeline

## Project Overview

**Project:** PayChauki  
**Approach:** Scrum-based Agile  
**Total Story Points:** 46  
**Number of Sprints:** 3

The project follows three planned sprints, moving from system foundation to fraud detection and then investigation, administration, testing, and deployment preparation.

## Timeline

| Phase | Focus | Main Deliverables | Story Points |
|---|---|---|---:|
| Sprint 1 | Foundation and Basic System | Registration, login/logout, roles, transaction recording, transaction history, basic UI | 12 |
| Sprint 2 | Fraud Detection | Fraud rules, risk levels, flagging, alerts, high-risk blocking | 21 |
| Sprint 3 | Investigation and Administration | Fraud reporting, analyst review, case management, user/rule management, testing and deployment preparation | 13 |
| Final | Prototype Demonstration | Testing results, resolved/documented defects, documentation, deployment and demonstration | — |

## Sprint 1 – Foundation and Basic System

**Goal:** Establish the core system and customer access.

### Planned Work
- User registration
- Secure login and logout
- User roles
- Transaction recording
- Transaction history
- Basic user interface

### User Stories
- US-01 – User Registration
- US-02 – Secure Login
- US-03 – Transaction History
- US-04 – Record Transaction

**Total:** 12 SP

---

## Sprint 2 – Fraud Detection

**Goal:** Implement the core fraud monitoring workflow.

### Planned Work
- Predefined fraud detection rules
- Risk level assignment
- Suspicious transaction flagging
- Fraud alerts
- High-risk transaction blocking

### User Stories
- US-05 – Fraud Detection
- US-06 – Fraud Alert
- US-07 – Block High-Risk Transaction

**Total:** 21 SP

---

## Sprint 3 – Investigation and Administration

**Goal:** Complete investigation and administrative functionality and prepare for testing and deployment.

### Planned Work
- Fraud reporting
- Fraud analyst dashboard
- Fraud case management
- User management
- Fraud rule management
- Testing preparation
- Deployment preparation

### User Stories
- US-08 – Report Fraud
- US-09 – Fraud Case Review
- US-10 – User and Rule Management

**Total:** 13 SP

---

## Testing Timeline

Testing is conducted throughout development and includes:

- Functional testing
- Security testing
- Integration testing
- System testing
- User interface testing
- Basic performance testing

## Final Project Activities

After implementation:

- Review test results.
- Resolve or document critical defects.
- Complete project documentation.
- Prepare the prototype for deployment.
- Prepare the final prototype demonstration.
